## Overview

A comprehensive collection of **supervised and unsupervised machine learning models** applied to diverse real-world datasets. This project serves as both a learning resource and a reference implementation for classical ML techniques, covering everything from regression and classification to clustering and dimensionality reduction.

---

## Key Features

- **Multiple algorithms** — Linear Regression, Logistic Regression, Decision Trees, Random Forest, SVM, KNN, K-Means, and more
- **Diverse datasets** — Real-world data from different domains
- **End-to-end workflows** — Data preprocessing, feature engineering, model training, evaluation
- **Visualizations** — Plots and charts for model performance and data insights
- **Comparative analysis** — Side-by-side comparison of model accuracies
